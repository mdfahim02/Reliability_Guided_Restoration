# Reliability Guided Image Restoration

## 1. Project Overview

This project performs image restoration using a deep learning model.

The model takes a degraded low-resolution noisy image as input and produces a restored high-resolution image.

The model is trained using paired:

- Noisy/Low-Resolution images
- Ground Truth images

The trained model is saved as:

`restoration_model.pth`

## 4. Model Architecture

The image restoration model is implemented in:

`model.py`

The model takes a degraded low-resolution grayscale image as input and generates a restored high-resolution image.

The overall processing flow is:

```text
Input Image
     ↓
Convolutional Feature Extraction
     ↓
Feature Processing
     ↓
2x Upsampling
     ↓
Image Restoration
     ↓
Restored High-Resolution Image

---

## 5. Training

The training process is implemented in:

`train.py`

The dataset loading functionality is implemented in:

`dataset_loader.py`

The model is trained using paired Noisy/Low-Resolution and Ground Truth images.

The trained model weights are saved as:

`restoration_model.pth`

### Run Training

From the project root directory, run:

```bash
python train.py

---

## 6. Inference

Inference is performed using:

`evaluation.py`

The script loads the trained model from:

`restoration_model.pth`

and performs inference on the specified test image directory.

### General Usage

```bash
python evaluation.py <test_images_directory> <output_directory>

---

## 7. Evaluation

The `evaluation.py` script is the standalone inference and evaluation entry point for the project.

It accepts two command-line arguments:

1. Test images directory
2. Output directory

### Usage

```bash
python evaluation.py <test_images_directory> <output_directory>

---

## 8. Evaluation Metrics

The restoration quality was evaluated using the following image quality metrics:

- Peak Signal-to-Noise Ratio (PSNR)
- Structural Similarity Index Measure (SSIM)

The metric calculation is implemented in:

`metrics.py`

The development evaluation results obtained were:

```text
Average PSNR : 27.17 dB
Average SSIM : 0.7213
